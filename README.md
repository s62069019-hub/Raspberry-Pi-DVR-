# Raspberry-Pi-DVR-



Фізичне підключення кнопки до Raspberry Pi 5Вам знадобиться звичайна тактова кнопка (без фіксації, яка замикає контакти лише в момент натискання):Один контакт кнопки підключіть до GPIO 26 (фізичний пін №37 на 40-піновому роз'ємі гребінки).Другий контакт кнопки підключіть до будь-якого контакту GND (Земля, наприклад, фізичний пін №39 поруч).
